
# PIYVIAN ORBIT

### One command center. Your world, in orbit.

PIYVIAN ORBIT is a Personal AI Operating System developed by PIYVIAN TECHNOLOGIES.

Its vision is to bring professional, personal, learning, and business workflows into one unified platform, coordinated by a central Supervisor and powered by specialist AI agents.

## Product Vision

- One unified AI Command Center.
- Specialist agents with dedicated workspaces.
- Shared context with controlled permissions.
- Human approval for consequential actions.
- Transparent workflows, evidence, and audit history.
- Future SaaS support for individuals and teams.

## Specialist Agents

- Supervisor / Orchestrator
- Career Intelligence
- Application Tracker
- PIYVIAN Client Agent
- Content / Social Media Agent
- Learning Coach
- Business Ideas Research Agent
- Finance Agent
- Personal / Family Health Assistant
- Property Assistant
- Personal Planner
- Admin Studio

## Engineering Principles

- Python-first backend.
- Modular monolith architecture.
- Deterministic services for rule-based operations.
- LLMs for language understanding and reasoning.
- Human-in-the-loop approvals.
- Automated testing and professional SDLC practices.
- Security, privacy, observability, and auditability.

## Development Status

Currently in Phase 0: Product Discovery and Engineering Setup.

## Technology Direction

Python, FastAPI, React, PostgreSQL, LangChain, LangGraph, MCP, RAG, and LangSmith — adopted progressively as requirements justify them.
